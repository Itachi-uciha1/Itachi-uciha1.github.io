FIFO Job Finder: privacy policy

Last updated 26 November 2026.

FIFO Job Finder is a personal tool used only by its owner. It is not offered to anyone else.

Google user data it accesses

  • Gmail (send): to send job application emails, written by the owner's automation, from the owner's own Gmail account.
  • Gmail (read-only): to read replies from employers to those applications, so they can be tracked.
  • Google Sheets: to record each application in the owner's own spreadsheet.

How the data is used and stored

Data is used only to run the owner's job search. It is not sold, shared with third parties, or used for advertising. Credentials are stored as encrypted secrets in the owner's private GitHub repository. Email content is processed only during each run and is not kept outside the owner's Gmail and Google Sheet.

Use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Revoking access

Access can be removed at any time at myaccount.google.com/permissions.
